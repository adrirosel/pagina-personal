# Página personal — Adrián Rosel Martínez

Sitio estático personal con HTML, CSS y JavaScript vanilla, desplegado en GitHub Pages.

**URL:** https://adrirosel.github.io/pagina-personal/

## Cómo ejecutar

```bash
npm install
npm test
npm start
```

`npm start` sirve la carpeta `site/` en http://localhost:8080.
